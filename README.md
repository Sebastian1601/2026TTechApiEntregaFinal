# 2026TTechApiEntregaFinal
API con autenticación, crud con express, jwt, firebase.

## Carpeta oficial de la entrega del proyecto NodeJS backend de TalentoTech

Módulos instalados:
- Express
- Cors
- JSon Web Token
- dotEnv
- Firebase


## Instalación
`npm init -y`


## Instalar dependencias
`npm install`
